# Maps

Drop map image files in this directory. Supported formats: PNG, JPG, JPEG, WEBP.

The GM control panel's "Load Map…" button opens a file dialog rooted here.

For best results follow the standards in `Wiki/Missions/Overview.md#vtt-map-conventions`:

- 140 px per 5-foot square (downscales cleanly to Roll20's 70 px standard)
- True 90° top-down, no perspective tilt
- Single NW light source across all play-surface maps for visual coherence
