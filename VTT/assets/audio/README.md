# Audio

- `music/` — background music tracks. Selected music plays looped with a ~1.5 s crossfade on track change.
- `sfx/` — one-shot ambient sound effects. Triggered fire-and-forget from the GM panel.

Supported formats: **OGG, MP3, WAV.**

OGG is the recommended format for music — Godot loops it most reliably and the file sizes are reasonable. MP3 also works. WAV is best for short SFX.
